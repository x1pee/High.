# Проверка платформ · 24.09.2026

## Подтверждено сейчас

Windows EXE Tauri собран. 82 теста расчётов/хранения прошли; браузерные проверки с макетом нативного IPC прошли при ширине компьютера и телефона. В этом выпуске реальный WebView2 отдельно не запускался, чтобы не прерывать открытую пользовательскую версию.

## Проверено в исходниках

- Rust: трей, single-instance и автозапуск подключаются только на компьютерах; winreg и mslnk — только Windows.
- На телефонах профиль использует app_data_dir, импорт/экспорт — файловый плагин с поддержкой URI. Системные кнопки окна и настройки автозапуска скрываются.
- Linux AppImage использует внешний APPIMAGE для автозапуска/ярлыка. CI содержит WebKitGTK 4.1, AppIndicator, libxdo-dev и другие зависимости.
- macOS: команды app/dmg; добавлен icon.icns. Сборка матрицы macos-latest ориентирована на архитектуру выбранного runner, не на универсальный бинарник.
- Android: CI устанавливает Java 21, SDK 35, NDK 27; инициализирует Tauri-проект и собирает debug APK aarch64.
- iOS: CI на macOS инициализирует проект и собирает aarch64-симулятор. Это не подписанный выпуск для iPhone.
- Сгенерированы штатные значки Tauri для всех платформ.

## Ограничение проверки

На текущей машине установлен только Rust target x86_64-pc-windows-msvc. Нет настроенных Java/Android SDK/NDK, установленного дистрибутива WSL и macOS/Xcode. Workflow четырёх платформ не запускался: текущая папка не является Git-репозиторием. Поэтому совместимость по архитектуре предусмотрена, но успешные сборки и работа Linux/macOS/Android/iOS ещё не подтверждены.

Для подтверждения нужны отдельные сборки на соответствующих runner и проверки: создание/редактирование/удаление дневника, перезапуск, сохранение темы, импорт/экспорт, сенсорное управление и клавиатура на телефоне. Для магазинов потребуются подписи.

Источники: https://v2.tauri.app/start/prerequisites/ и https://v2.tauri.app/plugin/dialog/ . Документация диалогов подтверждает поддержку всех платформ и URI на мобильных устройствах; это не заменяет испытание нашего приложения.
