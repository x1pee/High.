# VYSHE 1.9.9.3 — платформы и граница выпуска

## Windows

Windows x64 NSIS установщик собирается per-machine и устанавливает приложение в `C:\Program Files\Vyshe`; установка требует подтверждения администратора. Дневник и параметры остаются в `%APPDATA%\vyshe`. Установщик запускает обычное полное окно после установки. Системный автозапуск может передать `--background`, но только если отдельно включено открытие в трее. Настройки доступны в «Настройки» → «Приложение».

Ярлык рабочего стола создаётся кнопкой в настройках приложения. Для Windows и Linux используется один фиксированный путь `VYSHE.lnk` или `VYSHE.desktop`; если ярлык уже существует и ведёт на старую установку, кнопка обновляет его на месте, не создавая второй.

## Размер

Сборка Electron оставляет локали Chromium `en-US` и `ru`; это уже сэкономило около 49 МБ. Текущая распакованная папка занимает 339,554,387 байт, включая `Vyshe.exe` размером 246,236,160 байт; установщик — 103,433,857 байт. Перенос в Program Files эти размеры не уменьшает. Существенно меньшая установка потребует миграции на системный WebView/Tauri с повторной проверкой графика, трей-иконки, автозапуска и обновлений; это отдельная работа для 2.0.

## Linux и macOS

Linux x64 `tar.gz` для 1.9.9.3 собран: 117,516,377 байт. `tar -tzf` успешно прочитал все 21 записи, включая `resources/app.asar` и исполняемый файл `vyshe`. Локального Linux/WSL окружения нет, поэтому приложение на Linux не запускалось. macOS артефакт пока не собран. Workflow `.github/workflows/build-platforms.yml` настроен на Windows, Ubuntu и macOS для тега `v1.9.9.3`, но не запускался; файлы сайта не публиковались. Перед публикацией Linux/macOS пакетов нужен запуск на соответствующих системах.

## Android и iPhone

Проекты Capacitor синхронизированы для 1.9.9.3; мобильный браузерный интерфейс проходил проверку при ширине 390 px. Это не заменяет запуск на устройствах. Android APK и iPhone IPA для 1.9.9.3 не собраны. Для APK нужен Android SDK/Studio; IPA требует macOS и Xcode.

## Обновления

`desktop/release-channel.json` содержит `url: null`. Интеграция updater подготовлена, но реальная загрузка обновлений пока не настроена. В будущей публикации временные файлы обновления по-прежнему будут храниться в `%LOCALAPPDATA%\vyshe-updater`; текущие бинарные файлы приложения при установке будут в Program Files. Обновление установленной в Program Files программы должно пройти с системным подтверждением прав администратора. Настраиваемого каталога загрузки пока нет.
