# VYSHE 1.9.9.2 — платформы и граница выпуска

## Desktop

Windows x64 NSIS установщик собран локально. Он устанавливает программу per-user в `%LOCALAPPDATA%\Programs\Vyshe`, запускает приложение после установки и оставляет дневник отдельно в `%APPDATA%\vyshe`. Обычный запуск всегда открывает окно. При включённых автозапуске и запуске в трее скрытый режим используется только для старта системы с аргументом `--background`.

Linux x64 `tar.gz` собран локально: 117,514,385 байт; gzip/tar читается, но на Linux его пока не запускали. Проверенная AppImage ещё не собрана. macOS ZIP не собран на этой Windows-машине. Workflow `.github/workflows/build-platforms.yml` подготавливает сборки на Linux/macOS и сейчас слушает тег `v1.9.9.2`; workflow не запускался и файлы не публиковались. Не размещать Linux/macOS как проверенные загрузки до запуска на соответствующих ОС.

Windows установщик содержит Electron runtime и занимает 103,424,806 байт (~103 МБ); распакованная папка занимает 339,545,411 байт (~340 МБ). Оставлены только локали Chromium `en-US` и `ru`. До этого фильтра распакованная сборка занимала 388,401,451 байт — выигрыш около 49 МБ; размер установщика снизился примерно с 112 до 103 МБ. Сам `Vyshe.exe` занимает 246 МБ, тогда как `app.asar` с приложением — около 3 МБ. Дальнейшее значительное уменьшение потребует смены Electron на системный WebView/другую оболочку, то есть отдельной миграции и тестирования.

## Android и iPhone

Android/iOS проекты Capacitor синхронизированы через `npm run mobile:sync`. Мобильный интерфейс прошёл браузерную проверку при ширине 390 px: создание графика, запись, локальное хранение и перезагрузка страницы. Это не заменяет установку и проверку на телефоне.

Android APK не собран на этой Windows-машине: Android SDK/Studio не установлены. В workflow настроен `assembleDebug` как проверочный артефакт, но он не запускался. iPhone-сборка требует macOS/Xcode; IPA не собран. В мобильной версии используется локальное хранилище WebView/браузера; данные Windows сами на телефоне не появляются. Экспорт/импорт остаётся ручным переносом. Публикация в Google Play/App Store требует подписанных релизных сборок, устройств/симуляторов и аккаунтов владельца.

## Обновления и следующий этап

`desktop/release-channel.json` содержит `url: null`. Кнопка обновлений и updater-интеграция есть, но настоящее обновление ещё не загружается. После подключения HTTPS-канала electron-updater по умолчанию будет хранить временную загрузку в `%LOCALAPPDATA%\vyshe-updater`; папка для загрузок сейчас не настраивается. Переход между двумя установленными версиями с реального сервера не проверен.

План 2.0: выбрать новое имя приложения; подготовить и испытать публикационные сборки desktop/Android/iOS; разместить проверенные загрузки на сайте и подключить публичный HTTPS-канал обновлений; отдельно спроектировать синхронизацию с согласием пользователя и разрешением конфликтов. Перед сменой оболочки сначала измерить размер, затем сравнить Electron с Tauri/WebView на прототипе, сохранив tray, автозапуск и работу без сети. До проверки на целевых устройствах соответствующие пакеты не называть готовыми к выпуску.
