# Cascadia Code

Шрифт определён по computed style и CSS сайта https://starkow.dev/ (23.09.2026).
Бинарные файлы получены из `/CascadiaCode.woff2` и `/CascadiaCodeItalic.woff2` этого сайта.
Автор и основной репозиторий: Microsoft, https://github.com/microsoft/cascadia-code.
Лицензия SIL Open Font License 1.1 приложена в LICENSE-Cascadia.txt.
Файлы шрифта не модифицировались и используются локально; системная установка не нужна.
Оформление приложения самостоятельно адаптировано под терминал; код, тексты и цветовая схема сайта не копируются.
