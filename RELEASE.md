# Выпуск High. 2.0.0

Версия 2.0.0 объединяет видимую версию, package.json, Cargo и Tauri. Windows-релиз содержит только переносной EXE, подпись и latest.json. Английское описание с короткой русской частью находится в RELEASE-NOTES.md.

По решению пользователя 04.10.2026 репозиторий публичный. Встроенная проверка получает подписанный манифест через GitHub, подсвечивает доступное обновление и заменяет EXE после подтверждения. Сквозной тест 1.9.23 → 2.0.0 с контрольным дневником прошёл; данные сохранились. Подробности — AUDIT-2.0.md. Синхронизация остаётся ручной. Linux AppImage, macOS app и Android release APK собираются как QA-артефакты; это не подтверждение работы на физических устройствах. QA-сборки не требуют ключа updater и не создают setup/MSI/DEB/DMG.

## Историческая проверка 1.9

Состояние 27.09.2026: репозиторий приватный, анонимный манифест обновлений возвращает 404. Встроенное обновление из этого адреса сейчас недоступно. Сквозной тест ниже относится к периоду до приватизации. План авторизованного канала: [V2-READINESS.md](V2-READINESS.md).

GitHub Release `v1.9.23` содержит переносной Windows EXE и подписанный манифест для собственного механизма обновления. `package.json.appVersion` задаёт видимую версию 1.9.9.19; внутренняя версия Cargo/Tauri — SemVer 1.9.23. Установщики в релиз не попадают.

История в окне обновлений строится из последних записей `CHANGELOG.md`. Формат отображаемой версии принимает прежние четыре части (`1.9.9.17`) и обычный SemVer (`2.0.0`), поэтому переход к 2.0 не требует отдельного формата истории.

Запусти EXE двойным щелчком. Ручной запуск всегда открывает полное окно. Дневник и настройки хранятся отдельно в `%APPDATA%\Vyshe`. Обновление скачивает новый EXE во временный файл, проверяет подпись, закрывает текущий процесс, заменяет EXE и запускает новую версию. Данные дневника при этом остаются на месте. Нужен установленный WebView2 Runtime.

## Автоматические сборки и обновления

`.github/workflows/updater-release.yml` запускается для SemVer-тегов `v1.9.*` и `v2.*`, получает исходники авторизованным checkout, проверяет JavaScript и Rust, собирает `high.exe` без bundle-команды, переименовывает его в версионированный EXE, подписывает и публикует вместе с `.sig` и `latest.json`. В Windows-релизе нет setup-файлов, MSI и ZIP. `.github/workflows/tauri.yml` отдельно готовит платформенные QA-артефакты; ручной запуск `target=android` проверяет Android без выпуска релиза.

Публичный ключ и endpoint находятся в `src-tauri/tauri.conf.json`; приватный ключ доступен только GitHub Actions через `TAURI_SIGNING_PRIVATE_KEY`. Обновлятор сверяет версию, адрес релизного EXE и криптографическую подпись до замены программы. Сквозная проверка `1.9.22 → 1.9.23` прошла на отдельной копии EXE: загрузка совпала с опубликованным файлом по SHA-256, приложение перезапустилось, тестовая запись дневника сохранилась, а новая версия сообщила, что она актуальна.

GitHub Releases раздают файлы приложения и заметки выпуска, но не синхронизируют дневники. Для синхронизации используется отдельный Cloudflare Worker + D1; текущая передача дневника запускается вручную из «Настройки → Мои данные».

## Данные

- `%APPDATA%\Vyshe\journal.json` — активный дневник; `graphs\` — остальные графики.
- `deleted-graphs\` хранит удалённые графики для восстановления в течение 30 дней; `backups\` содержит ротационные резервные копии.
- `preferences.json` хранит запуск с Windows, запуск автозагрузчика в трее, проверку обновлений и завершение первого запуска.
- Избранные даты сохраняются в настройках самого дневника. Сводки недели/месяца вычисляются из записей и заметок, не добавляя данные в историю.

## Сервер и шифрование

Сервис синхронизации уже развёрнут на Cloudflare Free: Worker принимает зашифрованные на устройстве снимки и хранит их в D1. На каждом устройстве один раз импортируй один и тот же `cloudflare/local-credentials.json`, затем нажимай «Синхронизировать сейчас». Первая отправка требует подтверждения; при одновременных изменениях приложение предлагает выбрать локальную или облачную копию. Файл сопряжения содержит ключ и токен доступа — сохрани его отдельно и не загружай в GitHub. Детали и ограничения перечислены в `cloudflare/README.md`.
