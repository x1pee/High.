# High. — 1.9.9.19 (Tauri 2)

Личный дневник в виде свечного графика. Записи остаются локальными, пока ты явно не запустишь синхронизацию. Между устройствами можно вручную переносить зашифрованную копию через Cloudflare Worker + D1. Подробности и ограничения: [cloudflare/README.md](cloudflare/README.md).

## Запуск без установки

Установщик Windows появится в [GitHub Releases](https://github.com/x1pee/High./releases). Он включает проверку обновлений. Ранее собранный переносной EXE можно запускать из любой папки, но он обновляется вручную. Для окна используется WebView2 Runtime.

Записи, графики и настройки остаются в прежней папке `%APPDATA%\Vyshe`, чтобы High. сразу открывал существующий дневник. Это пользовательские данные, они не переносятся вместе с приложением и не удаляются при замене EXE.

Команды сборки и требования платформ описаны в [PLATFORMS-AND-SYNC-1.9.9.13.md](PLATFORMS-AND-SYNC-1.9.9.13.md). Linux, macOS, Android и iOS настроены в GitHub Actions, но их сборки и запуск на устройствах ещё не проверены.

В «Настройки → Приложение» можно включить запуск с Windows; тогда появляется отдельный флажок запуска в трее. Обычное открытие EXE или ярлыка всегда показывает окно. При переносе EXE открой его вручную один раз: включённый автозапуск обновит путь. Существующий ярлык можно обновить там же без создания второго.

Название приложения — High. Цвет точки следует выбранной теме.

## Новый график

Название по умолчанию — **LIFEUSDT**, начало — **100**, выбран стартовый ритм. Он показывает 30 временных свечей по часу и не добавляет событий или изменений индекса. Каждая новая запись постепенно убирает одну стартовую свечу; редактирование не возвращает их. Его можно скрыть кнопкой «Скрыть стартовый ритм».

После создания открывается график и отдельное окно монетки. Можно выбрать «Позже»: вместо монетки остаётся квадратная кнопка «+». Нажатие на неё возвращает редактор. Поддерживаются 15 цветов и свой HEX, геометрические символы и до пяти букв. Переключение символов сохраняет высоту редактора.

Пять готовых тем доступны с начала. Цвет свечей зависит от выбранной темы. Настройки графика сохраняются вместе с самим графиком.

## События

- Поле изменения принимает число, знак и десятичный разделитель. Буквы и посторонняя вставка блокируются; `inputmode="decimal"` запрашивает цифровую клавиатуру на мобильных устройствах. Текущая поставка — Windows; физическая телефонная клавиатура не проверялась.
- «Сейчас» скрывает дату и время. «Другая дата и время» открывает два компактных поля с календарём и выбором времени. Пять отдельных длинных списков убраны.
- Прошлые записи добавляются обычным нажатием. При включённом переходе к событию график показывает его день и возвращает понятный масштаб. Если переход отключён, сохранён выбранный пользователем вид.
- Будущая запись требует три нажатия: предупреждение, повторное подтверждение, сохранение. Изменение полей сбрасывает подтверждение. Такие записи участвуют в общей истории; график может показывать будущее, но обычные периоды «Сегодня / 30 дней» остаются привязаны к текущей дате.
- Проверка не разрешает новым событиям увести индекс ниже 0,01, включая последствия для следующих записей. Импорт старой истории сохраняет исходные данные.

## График

Свечи от минуты до года, несколько видов графика, MA 7/14/28, база, проценты, измерение и инструменты рисования. Объём реальных событий равен сумме модулей их изменений: сильные изменения дают высокие столбцы, слабые — низкие. Пустые промежутки окрашены приглушённо и не выглядят как реальные события.

После сохранения нового события строятся промежуточные свечи и короткий импульс с отскоками. Стартовый рисунок не анимируется повторно. Импульс использует **до/после именно этой записи**: отрицательное событие падает красным, даже если свеча за весь интервал остаётся положительной. Затем видна реальная итоговая свеча OHLC. Промежуточные кадры не записываются в дневник. При выключенной анимации или системном уменьшении движения эффект отсутствует.

Подсветка каждой свечи соответствует её направлению. Карточку можно читать и прокручивать, наведя на шапку, либо закрепить кнопкой. Отдельная кнопка «Читать карточку» убрана; вне режима чтения карточка не мешает перетаскиванию графика.

## Графики и архив

Меню содержит графики, демонстрационный пример и архив. Публичный блок «Для тестирования» удалён. Настройки/удаление графика находятся в компактном выпадающем меню.

После удаления график можно восстановить из «Недавно удалённых» в течение 30 дней. Если удалён последний график, ссылка восстановления доступна на начальном экране. Проверка срока выполняется при запуске и открытии архива; истёкший снимок заменяется отметкой об удалении. Ротационные резервные копии независимы от архива.

День можно отметить звёздочкой: избранное видно в отдельной вкладке. Вкладка «Сводка» показывает реальные итоги и события недели или месяца, оборот по сумме модулей изменений и заметки периода.

## Обновления и сайт

Переносной EXE из `npm run pack` остаётся без установщика и не обновляется сам. Установленная Windows-версия использует Tauri updater: при включённой настройке она сама проверяет GitHub Releases, а загрузка и установка требуют подтверждения в приложении. `.github/workflows/updater-release.yml` собирает подписанный NSIS-установщик и манифест `latest.json` по тегу `v1.9.*`; для выпуска в GitHub Actions нужно сохранить приватный ключ подписи в секрете репозитория. До первого подписанного релиза автообновление ещё нельзя проверить на установленной версии. Подробности: [RELEASE.md](RELEASE.md).

Синхронизация запускается вручную в «Настройки → Мои данные»: на каждом устройстве выбери один и тот же `cloudflare/local-credentials.json`, затем нажми «Синхронизировать сейчас». Первая отправка требует подтверждения; конфликты показывают выбор между локальной и облачной копией. Секреты сейчас хранятся в локальном хранилище приложения, а не в системном хранилище ключей.

## Разработка и проверка

- `npm ci`, затем `npm start` — установка зависимостей и запуск Tauri в режиме разработки.
- `npm test` — модель данных, график, дневник, объём, избранные дни и сводки.
- `npm run qa:tauri:layout` — браузерная проверка большого и мобильного экрана.
- `npm run pack` — Windows EXE без установщика (`src-tauri/target/release/high.exe`).
- `npm run qa:tauri` — запуск реального WebView2 EXE с изолированным тестовым профилем; сначала собери приложение.
- `npm run pack:linux` и `npm run pack:mac` — сборки на Linux/macOS. Android/iOS команды и требования — в платформенном руководстве.
- `VYSHE_DATA_DIR` задаёт изолированный профиль для native QA; это сохранённое имя тестовой переменной.

Результаты и границы проверки: [AUDIT.md](AUDIT.md). История изменений: [CHANGELOG.md](CHANGELOG.md).
