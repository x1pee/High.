# VYSHE 1.9.9.4 — фактическое состояние платформ

## Windows

Основная поставка — Vyshe-1.9.9.4-Portable.exe, 92 940 970 байт. Локальная копия для пользователя называется ../Vyshe.exe. Установки и повышения прав не требует. Собрана командами npm test, npm run pack; выполнены source UI QA и npm run qa:portable на самом упакованном EXE.

Проверено: ручной запуск показывает окно; --background при сохранённых autoStart/tray запускает в трее; повторное открытие внешнего EXE показывает существующее окно; запись остаётся после перезапуска; временный runtime удаляется после выхода. На этой машине запуск в изолированном тесте занимал 8,5–8,9 секунды, включая распаковку. Сам вход Windows заново не выполнялся.

Автозапуск и ярлык используют PORTABLE_EXECUTABLE_FILE, а не путь распакованного приложения. После перемещения EXE включённая запись автозапуска обновляется при ручном открытии. Ярлык обновляется через настройки. Обычное закрытие завершает приложение, запуск в трее относится только к автозагрузке.

По выбору пользователя профиль остаётся в %APPDATA%\Vyshe. EXE на другом компьютере без переноса профиля не содержит старого дневника. Для переноса доступны JSON импорт/экспорт и резервные копии.

При работе остаётся временный runtime Electron размером около 340 МБ плюс сам EXE. Максимальное сжатие уменьшило файл поставки относительно прежнего установщика с 103 433 857 до 92 940 970 байт; движок не стал меньше. Существенное уменьшение runtime описано в PRODUCT-NEXT.md.

## Linux, macOS и мобильные платформы

Последний локальный Linux x64 tar.gz относится к 1.9.9.3; проверено чтение архива, не запуск на Linux. macOS ZIP не собран. Сборки Linux/macOS 1.9.9.4 на этой машине не выполнялись.

Android/iOS проекты синхронизированы с web assets 1.9.9.4 через Capacitor. APK/IPA не собраны; JDK/Android SDK и macOS/Xcode отсутствуют. CI описывает целевые runners, но workflow не запускался и артефакты не публиковались.

## Обновления

Публичный канал отсутствует. Для portable NSIS updater отключён даже при заданном URL: он устанавливает программу и не подходит для замены переносимого EXE. Текущий способ — закрыть приложение и заменить файл. Будущий механизм замены и отката описан в RELEASE.md. Сборка без подписи издателя.
